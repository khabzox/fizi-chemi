# Prompt Complet: Expérience Interactive sur Les Ressorts

## 2ème Année Baccalauréat Sciences Mathématiques - Maroc

### Contexte Pédagogique

Créez une expérience d'apprentissage interactive et immersive sur le chapitre "Les Ressorts" destinée aux élèves de 2ème année Baccalauréat Sciences Mathématiques au Maroc, conforme au programme officiel du Ministère de l'Éducation Nationale.

### Objectifs d'Apprentissage

L'expérience doit permettre aux élèves de :

- **Comprendre** les propriétés fondamentales des ressorts (élasticité, déformation)
- **Maîtriser** la loi de Hooke et ses applications
- **Analyser** les mouvements oscillatoires harmoniques simples
- **Calculer** les grandeurs physiques (période, fréquence, amplitude, énergie)
- **Résoudre** des problèmes complexes liés aux ressorts
- **Visualiser** les phénomènes physiques abstraits

### Contenu Scientifique à Intégrer

#### 1. Notions Fondamentales

- **Élasticité et déformation** : définitions, types de déformation
- **Loi de Hooke** : F = -kx (force de rappel, constante de raideur)
- **Limite d'élasticité** et domaine de validité
- **Énergie potentielle élastique** : Ep = ½kx²

#### 2. Oscillations Harmoniques Simples

- **Équation différentielle** : d²x/dt² + (k/m)x = 0
- **Solutions mathématiques** : x(t) = A cos(ωt + φ)
- **Grandeurs caractéristiques** :
  - Période : T = 2π√(m/k)
  - Fréquence : f = 1/T = (1/2π)√(k/m)
  - Pulsation : ω = 2πf = √(k/m)

#### 3. Énergie dans les Oscillations

- **Énergie cinétique** : Ec = ½mv²
- **Énergie potentielle** : Ep = ½kx²
- **Énergie mécanique** : Em = Ec + Ep = constante
- **Conservation de l'énergie** et transformations

#### 4. Applications Pratiques

- Ressorts en série et en parallèle
- Systèmes masse-ressort horizontal et vertical
- Pendule élastique
- Amortissement et résonance (notions)

#### 2. Physique Interactive

```javascript
// Intégration Three.js - Simulation physique
const scene = new THREE.Scene();
const renderer = new THREE.WebGLRenderer({ antialias: true });
const camera = new THREE.PerspectiveCamera(
  75,
  window.innerWidth / window.innerHeight,
  0.1,
  1000
);

// Système masse-ressort 3D
class SpringSystem {
  constructor(mass, springConstant, amplitude) {
    this.mass = mass;
    this.k = springConstant;
    this.amplitude = amplitude;
    this.omega = Math.sqrt(this.k / this.mass);
    this.period = (2 * Math.PI) / this.omega;
  }

  updatePosition(time) {
    return this.amplitude * Math.cos(this.omega * time);
  }
}
```
